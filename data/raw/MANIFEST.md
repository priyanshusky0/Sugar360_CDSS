## How to compute a SHA-256 checksum (macOS)

A SHA-256 checksum is a fingerprint of a file. If even one byte changes, the
fingerprint changes completely. It proves the file we extracted from is the
same file listed here.

From the `sugar360-cds` folder, in Terminal:

```bash
shasum -a 256 data/raw/documents/ada/dc26s002.pdf
```

To fingerprint every PDF at once (including subfolders):

```bash
find data/raw/documents -name '*.pdf' -exec shasum -a 256 {} +
```

Compare the 64-character hex string with the table. Dates use YYYY-MM-DD.
